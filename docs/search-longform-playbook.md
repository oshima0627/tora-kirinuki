## 3. 他の長尺との比較

- **元動画の公開から7日以内に出した長尺 26本: 検索合計 45,924回（中央値13）。8日以上あとの 55本: 合計 402回（中央値4）。** 検索が付いた上位10本はすべて元動画から1〜5日以内。
- ただし7日以内でも 11月の aRXAyZrNcmg（1日後）・V_oBQc6p6tA（2日後）・MFf08_5r-bo（1日後）は検索 0〜9。**鮮度は必要条件だが十分条件ではない。**
- 長尺81本の検索再生の中央値は **7回**。100回を超えたのは7本だけ。
- 上位語の形はほぼ **「令和の虎 ＋ 商材・業種（下着／沖縄料理／弁理士）」「令和の虎 ＋ 地名（山形）」「志願者名（瀬戸麻希・大野詩織）」「令和の虎 ＋ 虎の名前（川島）」**。決め台詞（「帰ってもらっていい？」等）で探す語はほぼ無い（「1時間遅刻」27、「遅刻」21 程度）。
- 推測: 検索が付くのは「元動画が出て数日のうちに話題になった回」。話題になるかは公開前には分からないので、**新しい回を早く出す本数を増やす**のが現実的な打ち手。

## 4. 型（日次の長尺はこれに沿う）

### 題材選び
1. **令和の虎Second の新しい回を、元動画の公開から3日以内（遅くても7日以内）に長尺にする。** 古い回の残り区間より優先する。
2. 同じ回の長尺は最大2本。3本目以降は検索語の取り合いになる（V3gQ の例。推測）。
3. 商材・業種・地名が一言で言える回を優先（「下着」「沖縄料理」「弁理士」型）。抽象的な事業（「〇〇な社会をつくる」）は後回し。
4. 元動画の再生が公開2〜3日で他の回より速く伸びている回を優先（推測。API で元動画の viewCount を見て比べる）。

### タイトル型
`【令和の虎】{商材・業種}の{志願者名}さんに虎「{一言}」希望額{金額}→{結末・争点}{尺}分【令和の虎Second 切り抜き】`
- **検索語（商材・業種 > 志願者名 > 地名・虎の名前）をタイトルの前半40字以内に入れる。** 現状の「虎「…」…」先頭型は検索語が後ろに来る。
- 数字は本編のテロップどおり。結末を偽らない（「判定は本編で」系の釣りは長尺では使わない）。
- 人格を攻撃する語（「ヤバい」「クズ」等）は使わない。「公式」「公認」「マネーの虎」は禁止。

### 検索語の置き方
- タイトル: 主語1つ（商材・業種）＋志願者名。
- 概要欄1行目: これまでどおり「自分ならどうするか」の問い。その問いの中に商材・業種を入れる。
- 概要欄2〜4行目: `{版}令和の虎 {N}人目 {志願者名}さん／{地名}の{業種}／希望額{金額}` を地の文で（キーワードの羅列はしない）。
- タグ: 商材・業種の言い換え（例: 下着／ブラ）、志願者名、版名、出てくる虎の名前。

### 冒頭
- 0秒目から本題（11/2 ルール継続）。案件カード（0〜4秒）に **商材・業種と志願者名** を大きく出す。検索した人が「探していた回だ」と3秒で分かるようにする。
- 区間は「検索語の場面（事業の説明か、判定の直前）」から始まる連続区間を選ぶ。ガイドライン2項により連結・並べ替えはしない。

### 尺
- **15〜20分の連続区間**（当たった4本は 15:01〜20:01）。6〜9分のまとめは検索流入で差が出ていない（台帳 11/12 レビュー）。
- 1本の総再生時間を伸ばすため、平均視聴率 35〜40%（YY7z・tdrG 水準）を目標にする。

### 概要欄
- 1行目の問い → 回の要約（地の文・2〜3文） → 【元動画】タイトルとURL → 定型（CREDIT）。
- 区間の中身（何が詰められ、どう判定されたか）を事実だけで書く。

### NG
- 「ブラジャー」「Gカップ」「グラマー」など身体を連想させる語を **タイトル・サムネに出して** 検索を取りにいくこと（性的な強調は誤解・広告不適合・出演者の名誉の観点で不可。商材名「下着」は事実なので可）。
- 検索語を概要欄・タグに羅列すること（スパム扱いの恐れ）。
- 本編にない結末や数字、煽り（誇張）。
- 前後編の本編をつなぐ・順番を入れ替える編集（権利者ガイドライン2項）。
- 禁止素材: R05BBh55p_U、xfr6w7g_Xuc の34分以降、HowwrqNF9gw、UBqSUTamZ3M、病気・自殺未遂・うつの話。令和の虎Channel・Youth からは切らない。
