## なぜ新規に作るのか

2026-08-31 時点でブラウザにログインしていたのは **別アカウント**でした。

| 項目 | 値 |
| --- | --- |
| 表示名 | しま |
| ID | `30362060737` |
| フォロワー | 19 |
| 既存の投稿 | AI生成らしき風景・人物画像が5本（令和の虎とは無関係） |

ここへ投稿すると**許諾条件そのものに反します。**

1. **ガイドライン4項「チャネル名に『切り抜き』の文言を明記すること」** を満たさない
2. キャプションの `CREDIT`（「ガジェット通信クリエイターネットワークに申請済みの
   切り抜きチャンネルです」）が**虚偽になる**。申請したのは YouTube の
   `@reiwanotora-second2` であって、このアカウントではない

**照会を待つかどうかとは別の問題。** 照会不要と判断しても4項は明文の条件なので、
名前に「切り抜き」が入っていないアカウントへの投稿はどう転んでも条件違反になる。

## 設定する内容

| 項目 | 設定値 | 根拠 |
| --- | --- | --- |
| 表示名 | **図解でわかる令和の虎【切り抜き】** | ガイドライン4項。YouTube 側と同じ名前に「切り抜き」を付ける |
| ユーザー名 | `reiwanotora_zukai` など空いているもの | — |
| 自己紹介 | 下記 | ガイドライン5項（「公式」「公認」を書かない） |
| プロフィールのリンク | `https://www.youtube.com/@reiwanotora-second2` | 元動画への導線と、YouTube 本体への送客 |

自己紹介に入れる文（そのまま貼れます）:

```
令和の虎Second の切り抜きに図解を重ねています。
本チャンネルはガジェット通信クリエイターネットワークに申請済みの切り抜きチャンネルです。公式チャンネルではありません。
YouTube → https://www.youtube.com/@reiwanotora-second2
```

**「公式」「公認」とは絶対に書かない。** ロゴも使わない（アイコンは自作のものを使う）。
