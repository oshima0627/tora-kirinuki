## 2. 長尺は「クリックされない」のではなく「表示されていない」

Studio > アナリティクス > コンテンツ（過去28日 = 2026/07/28〜08/24）の漏斗。
**この指標は長尺だけのもので、ショートフィードは含まない。**

```
インプレッション数            2,387
  YouTube によるおすすめ      2.6%
クリック率                    3.1%
インプレッションからの視聴回数   73
平均視聴時間                  1:18
インプレッションからの総再生時間  1.59 時間
```

読み方:

- **CTR 3.1% は異常ではない。** サムネイルとタイトルを直しても、母数が2,387では何も動かない
- **母数の2,387が異常。** 15分の動画15本を28日出して、表示が2,387回しかない
- **おすすめ由来 2.6%（約62回）。** YouTube が長尺を配信していない
- **平均視聴時間 1:18 / 15分 = 8.6%。** 配信されない理由はこれ

トラフィックソース（同期間・チャンネル全体）:

| 経路 | 割合 |
|---|---|
| ショート フィード | 96.9% |
| YouTube 検索 | 1.5% |
| その他の YouTube 機能 | 1.0% |
| チャンネル ページ | 0.5% |
| **ブラウジング機能** | **0.0%** |
| 外部 | 0.0% |

**ホーム画面には一度も出ていない。**

Analytics API で長尺6本（08-20〜08-25公開）に絞ると、期間中の流入は**合計9再生**:
`YT_SEARCH` 4 / `YT_CHANNEL` 2 / `EXT_URL` 2 / `NO_LINK_OTHER` 1。**おすすめ由来はゼロ。**
