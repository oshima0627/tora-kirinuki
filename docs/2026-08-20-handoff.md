## 次にやること

### 1. 残りのアップロード（4本＝長尺4・ショート4）

`akutsu-hantei` / `imamura-ai` / `komazawa-ginkou` / `yotsui-kakkoii` が未投稿。
クォータは太平洋時間の0時（JST 16〜17時）に戻る。1日6本ずつなので8/21に3ペア、
8/22に1ペア。公開日は8/26以降に振る。**長尺を先に上げること**
（ショートの概要欄が長尺のURLを持つので、長尺が `published.json` に無いと止まる）。

```bash
python scripts/upload_youtube.py work/<id>       --schedule "<日>T03:10:00Z"   # JST 12:10
python scripts/upload_youtube.py work/<id>-short --schedule "<日>T03:00:00Z"   # JST 12:00
```

`state/published.json` に入っているものが投稿済み。入っていないものが残り。

### 2. ショートの2本目を作る

**新ルールの「1日ショート2本」は、いまの在庫では埋まらない。**
ショートの概要欄は親の長尺へのリンクを持つので、まだ公開されていない長尺の
ショートを先に出せない。結果として並びはこうなる。

| 日 | 長尺 | ショート1 | ショート2 |
| --- | --- | --- | --- |
| 1日目 | A | A-1 | （無し） |
| 2日目 | B | B-1 | A-2 |
| 3日目 | C | C-1 | B-2 |

**つまり長尺1本につきショートが2本要る。** いまは1本ずつしか無い。
2本目の候補は各レシピの `points` から選べる（15分の中に山は複数ある）。
`build_short.py` は `recipe["short"]` を1つだけ読むので、
**2本目を作るなら `shorts` 配列に対応させる改修が要る**（未着手）。
