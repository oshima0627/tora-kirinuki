# 視聴者参加（エンゲージメント）方針

承認: 2026-10-15（大島さん）。**常設の方針。** 日次制作（14:07 JST）と夕方ジョブ（18:35 JST）の両方に適用する。
既存の切り抜きルール（`docs/daily-workflow.md`「守ること」・権利者ガイドライン）は**すべてそのまま有効**。この文書はそれに上乗せするだけで、緩めるものは無い。

## トーン

- **図解・ビジネスの学び系。** 煽り・揶揄・出演者いじりはしない
- 問いは**「自分ならどうするか」**の型にする。答えられる問いにする（呼びかけだけではコメントは増えない）
  - 例: 「あなたが虎なら出資する？しない？理由もコメントで」
  - 例: 「この事業の改善案をコメントで」
  - 社長ファイトクラブ版など金額を出さない回は「あなたが虎なら支援する？しない？」

## (a) 動画内の問いかけテロップ（朝の日次制作・自動）

| 種別 | 位置 | 既定の文言 | 実装 |
|---|---|---|---|
| 長尺・冒頭 | 案件カードの直後（4.5秒〜、6秒間） | 「あなたが虎なら出資する？最後に答えを聞きます」 | `build_clip.py` `cta_plan()` / `cards.render_cta()` |
| 長尺・終盤 | 判定カードの直前（6秒間） | 「あなたならどうする？コメントで／学びになったら高評価・チャンネル登録を」 | 同上 |
| ショート・締め | 最後の4秒、上帯の見出しを差し替え | 「あなたが虎なら出資する？しない？理由もコメントで」 | `build_short.py` `closing_cta()` / `cards.render_short_cta()` |

- 長尺は**上帯**（論点カードと同じ白地・不透明、目印は左の金帯）。元動画は画面下に大きなテロップを常時焼いているので下には置かない
- 論点カードと時間が重なるときは、まず前後に最大20秒ずらす。空きが無ければ論点カードの直下（画面高さ22%）に積む
- ショートは上帯（黒）に見出しと同じ縁取り文字。**下帯の字幕は覆わない**
- 本編が短すぎる（約27秒未満）長尺は冒頭を省いて終盤だけ出す

## (b) 概要欄

- **1行目は問い**（`recipe.build_description()` が自動で入れる）。その直下（2〜3行目）に【元動画】タイトルとURL（権利者ガイドラインの必須条件）。手で書かない
- ショートは従来どおり元動画URLの直後に「▼この回をフルで見る」＋長尺URL（`upload_youtube.with_long_form_link()`）

## レシピの項目（すべて任意。無ければ既定を使うので旧レシピもそのまま動く）

| 項目 | 内容 | 既定 |
|---|---|---|
| `cta_question` | その回の問い（核）。概要欄1行目・ショートの締め・固定コメントに使う | `question` → タイトル/案件カードから「出資する？しない？」か「支援する？しない？」 |
| `cta_start` | 長尺冒頭のテロップ | 問いの最初の「？」まで＋「最後に答えを聞きます」 |
| `cta_end` | 長尺終盤のテロップ（「／」で改行） | 「あなたならどうする？コメントで／学びになったら高評価・チャンネル登録を」 |
| `shorts[i].cta_question` | そのショートだけ別の問いにする | `cta_question` |
| `cta` | `false` で全部無効（テロップ・概要欄1行目とも） | `true` |

問いに「コメント」が入っていなければ「理由もコメントで」を自動で足す。
`validate()` が「公式」「公認」「マネーの虎」「プレゼント」「抽選」「謝礼」「相互登録」などと URL を含む問いを落とす。

## (c) 夕方ジョブ（18:35 JST）でやること

1. **固定コメント**: 当日の長尺とショートにチャンネルのアカウントで問いを1件ずつ投稿してピン留め
   - 投稿: `python scripts/post_question.py recipes/<id>.json --apply`（長尺＋ショート。既に投稿済みなら飛ばす。公開前の動画は飛ばす）
   - **ピン留めは YouTube Data API に無い**（2026-09-10 実測）。Studio で手で行う
2. **終了画面**: 長尺に「チャンネル登録」要素＋関連動画（当日のショートか直近の関連回）。API に無いので Studio で設定
3. **ショート → 長尺の関連動画**: 当日同士のみ（従来の夕方ジョブ）
4. **コメント返信**: 直近7日の新着コメントに短く返信。**1日20件程度まで**
   - 返信は1〜2文。お礼＋中身への一言（「〇〇の視点、学びになります」など）。定型文の連投はしない
   - **返信しない（無視・必要ならStudioで非表示）**: スパム、誹謗中傷・荒らし、**出演者への攻撃**、個人情報を含むもの、宣伝・勧誘
   - **大島さんに上げる（返信しない）**: 炎上しそうなもの、権利・削除の申し立て、出演者・関係者を名乗るもの、判断に迷うもの
   - API は `commentThreads.list` / `comments.insert`（要 `youtube.force-ssl`。2026-10-15 時点の token.json に含まれる）

## 禁止

- 自分たちの動画に、bot・別アカウントで高評価・チャンネル登録・コメントをすること（チャンネルのアカウントによる固定コメントと返信だけは可）
- 有償・見返り付きのエンゲージメント依頼（「登録してくれた方にプレゼント」「相互登録」等）、外部サービスでの購入
- 「公式」「公認」と書くこと（テロップ・概要欄・コメント・返信すべて）
- 出演者の名誉・信用を害する問い・返信（「この人ダメだよね？」型の問いは作らない）
