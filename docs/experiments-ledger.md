## 実験の定義

**n = 2026-10-29 からの日数（JST の公開日で数える。10/29 が n=0）。**

### A+B（毎日・ショート）数字ズレ型

- 尺は **約10〜15秒（最大20秒）**。**最初の8秒以内**に「断言」→「数字の食い違い」が出て、**同じ区間の中で解決する**自己完結の切り抜き
- タイトル: **「【数字ズレ#N】<出演者名や題材＋何が起きたか>」**。N は 2026-10-29 が #1 の通し番号。**秒数はタイトルに入れない**
- その素材に該当する場面が無ければ、**従来の50〜58秒のショートにフォールバック**し、台帳の備考に `fallback` と書く（`experiment.variant.short = "fallback"`）
- 概要欄1行目は従来どおり「あなたが虎なら…」の問い。続けて「▼この回をフルで見る」＋長尺URL（従来どおり自動）

### D（ショートの締め）

- **偶数 n**: ショートの最後の画面上の一行を **「判定は本編で」** にする（問いの代わり）
- **奇数 n**: 従来の締めの問い
- **概要欄1行目は両方とも問い**のまま

### C（長尺）

- **奇数 n**: **6〜9分の図解まとめ**。最も検索されやすい・印象的な場面を**最初の30秒**に置く。タイトルは事業・商品・テーマで検索されやすい形にし、**下着・ブラのようなキーワードに頼らない**。人への攻撃的な表現は使わない
- **偶数 n**: 従来の13〜20分の長尺
- 14日で各7本ずつ

### 却下

- **プランE（同じ回から2本のショート）は実施しない。** `experiment` 付きのレシピは `shorts` が2本以上だと `validate()` が落とす

### 常に守る（変更なし）

- 「公式」「公認」と書かない／令和の虎Channel・Youth は切らない／**1日の公開は6本まで**
- 禁止素材: `R05BBh55p_U`、`xfr6w7g_Xuc` の 34:00 以降、`HowwrqNF9gw`、病気の話
- `docs/engagement.md`: CTAテロップは長尺の冒頭＋終盤・概要欄1行目は問い。**自作自演の高評価・登録・コメント、見返り付きの依頼は禁止**
- タイトル・テロップで出演者を傷つけない・個人を攻撃しない

## パイプラインでの作り方（レシピ）

すべて任意項目で、無ければ従来どおり動く。

```jsonc
"format": "matome",                  // 長尺。6〜9分（360〜540秒）だけ通す。無ければ従来（長さを検証しない）
"short": {
  "format": "kazuzure",             // 8〜20秒だけ通す（狙いは10〜15秒）。巻き戻し後の長さで測る
  "start": 1078.4, "end": 1090.4,
  "hook": "…", "head": [[{"t": "…", "c": "w"}]],   // head は従来どおり必須級（上帯）
  "title": "【数字ズレ#1】迫さん「利益2000万円」なのに2億円が凍結された",
  "ending_text": "判定は本編で",        // 偶数 n。省略しても experiment.variant.ending=hantei なら自動で入る
  "cta_sec": 3.0                      // 締めの帯の秒数。既定は standard 4秒／kazuzure 3秒
},
"experiment": {
  "id": "2026-10-29-format-test", "n": 0, "series_no": 1, "date": "2026-10-29",
  "variant": {"short": "kazuzure", "ending": "hantei", "long": "standard"}
}
```

- `validate()` が落とすもの: 偶数 n で締めが hantei でない／長尺が standard でない、奇数 n でその逆、`date` と `n` の食い違い、ショートが2本以上（プランE）、`cta:false`、`short.format` と `variant.short` の不一致、数字ズレ型でタイトルが「【数字ズレ#N】…」でない・N が `series_no` と違う・秒数が入っている
- **ショートのタイトルにも「公式」「公認」「マネーの虎」の禁止語を見る**（従来は長尺のタイトルしか見ていなかった。数字ズレ型でなくても有効）
- 区間探し: `python scripts/find_short.py <id> --format kazuzure --from <分> --to <分> --letterbox`（`--min 10 --max 15` と同じ。探す帯は既定の15〜25分なので、断言の場面に合わせて広げる）
- `experiment` は `work/<id>[-short]/meta.json` に写る（`upload_youtube.py` は読まない。**公開後の紐づけはこの台帳に手で書く**）

## パイプラインの限界（作る前に知っておくこと）

- **「最初の8秒以内に断言→数字の食い違い→同じ区間で解決」は機械では確かめられない。** 人が字幕・映像で確認する（find_short は文頭着地の候補を出すだけ）
- 数字ズレ型は **巻き戻し後の長さ** が8〜20秒でなければ落ちる。開始点は文頭に自動で巻き戻るので、短い区間ほど `--dry-run` で実際の開始・尺を見る
- **締めの帯は上帯（見出し）を差し替える**。3秒でも見出しが隠れるので、断言の見出しは8秒以内に見せ切る。下帯の字幕は覆わない
- **長尺の「最も印象的な場面を最初の30秒に」は、1本の連続区間でしか切れない。** ガイドラインが分割した本編の連結（順序を入れ替えた編集）を禁じているため、**目玉の場面から始まる連続した6〜9分を選ぶ**しかない。冒頭のダイジェストを作る機能は無い
- 長尺の案件カードは 0〜4秒、冒頭の問いかけは 4.5秒〜（`build_clip`）。6〜9分でも冒頭・終盤の問いは自動で入る
- 長尺の検索向きタイトルの良し悪し（下着・ブラ系に頼らない・攻撃的でない）は**人が判断**する。コードは禁止語（公式・公認・マネーの虎）しか見ない
- 偶奇・日付の整合は `experiment.n` / `date` で検査するが、**今日が何日目かはレシピ作成時に人（日次ジョブ）が数える**。台帳の表で確認すること
