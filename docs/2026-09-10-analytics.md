## 7. 次に測ること（施策と、答え合わせの形）

### A. ショートの尺を 50〜58秒にする ← 最優先・追加コスト0

HANDOFF の候補探索を `t+65 <= x <= t+73` から **`t+50 <= x <= t+58`** に変える。

- 根拠: 実視聴秒 39.5秒が尺と無相関（-0.02）／尺×平均視聴率 -0.53
- **答え合わせ**: 次の5本の平均視聴率の中央値を **既存19本の中央値 60.9%** と比べる。
  60秒以下で作った既存7本の中央値は 66.7%。**70%を超えれば効いたと言える。**

### B. トレーラーを差し替える ← 5分で終わる

`VwO47R4gGsE`（2再生）→ **`0V9WKZLW2Dw`（8/31・平均視聴率 85.7%・6,325再生）**。

- **答え合わせ**: YT_CHANNEL 経由の再生と、そこからの登録。

### C. 「図解」をショートに入れる ← 差別化の本体

論点カードを1〜2枚、**7秒あたり**（＝いま落ち始める地点）に入れる。

- 根拠: 7秒地点の残存が上位98〜119% / 下位90〜98% で分かれている
- **答え合わせ**: 5本作って 7秒・10秒地点の残存を、既存の中央値（7秒 99%・10秒 89%）と比べる
- **注意**: これは仮説。**尺を短くする施策（A）と同時にやると、どちらが効いたか分からなくなる。
  Aを先に5本、そのあとCを5本。**

### D. 長尺をどうするか ← 大島さんの判断が要る

31本で286再生（外れ値を除けば1本5.0）に対して、クォータの半分と1本15分の制作。
**「なぜ0再生でも作るのか」の答えがあるなら続ける。無いなら止めて、その枠をショートに回す。**
止めた場合、1日のクォータ 10,000 でショート **6本**（1,650×6＝9,900）が出せる。

### E. 固定コメントで問いを1つ投げる

コメント合計7件。「あなたが虎なら出資しますか」など、判定が割れる回だけでいい。

- **答え合わせ**: コメント数。5本で0件なら効かない。
